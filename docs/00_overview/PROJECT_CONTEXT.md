# Projektkontext

SGRS SwimPlan digitalisiert eine bestehende Excel-Saisonplanung für den Schwimmsport.

Die Anwendung unterstützt:
- Saisonziele und Wettkämpfe
- Makro-, Meso- und Mikrozyklen
- Mikrozyklussegmente
- Strength, Aerobic, Anaerobic, Speed, Tactical, Technical als parallele Entwicklungsstränge
- Target RPE und Zielumfang pro Mikrozyklus
- mehrere Sessions pro Tag
- Session-Metadaten statt Einzelserien
- Ausrüstung und Hinweise
- Saisonmatrix, Woche, Timeline, Dashboard

## Öffnungsmodell
Alle Besucher dürfen lesen und bearbeiten. Deshalb keine personenbezogenen Athletendaten, kein individuelles Feedback und keine Gesundheitsinformationen.

## Excel-Vorbild
Die Excel-Logik mit Month/KW/Date, WK/WK M, Ferien, Macro, Strength, Aero, Anae, Speed, Tactical, Tech, Meso, Mic RPE sowie Fokus/Main/Tech wird vollständig abgebildet.
